# STILL — Mind & Concentration Sanctuary

A minimalist, science-backed digital health and concentration reset application designed around deep focus, restorative wind-down routines, and distraction-free cognitive clarity.

---

## ✦ Core Pillars & Features

- **Concentration & Focus Reset**:
  - 15m, 20m, 25m focus blocks with adaptive micro-break pacing.
  - Distraction interceptor ("Brain Dump") with categorized parking: *Park in Worry Log*, *Label & Release*, or *Focus Next*.
  - Zen Mode full-canvas focus with dynamic tab titles and subtle breath ring.
  - Spacebar shortcuts & quick +5m extensions.

- **Sleep & Restorative Wind-Down**:
  - Target sleep window protection (e.g., `23:00 → 07:00`) with visual countdown.
  - 30m / 45m screen-dimming wind-down timer.
  - Bedtime Brain Dump for peaceful mental unburdening before sleep.
  - Integrated 432Hz harmonic drone & rainfall ambient generator with 15m/30m/45m sleep timers.

- **Daily Anchors & Hydration Rhythm**:
  - 6-glass daily hydration tracker synchronized with morning wake anchors.
  - Morning sunlight & posture/movement anchor check-ins.
  - Evening reflection journal with local data persistence.

- **Native Mobile & Desktop Ergonomics**:
  - Zero-horizontal-overflow responsive architecture.
  - Thumb-reachable floating island dock on mobile devices.
  - Compact adaptive UI controls (e.g. "Begin" on mobile, "Begin Stillness" on desktop).
  - Installable PWA with offline service worker support and dark/light bone themes.

---

## 🛠 Technology Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Vanilla CSS (Tailored HSL tokens, glassmorphism, fluid typography)
- **Icons**: Lucide React
- **Audio Engine**: Web Audio API (Synthesized Brownian noise, rain generator, 432Hz sine tone, singing bowl chime)
- **Deployment**: Compatible with static hosting and Apache cPanel subdomains via `.htaccess`.
